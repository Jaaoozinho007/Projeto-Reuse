# Projeto-Reuse
Projeto acadêmico destinado à trocas e doações de itens que não se utilizam mais pelo usuário.

Feitos de cada integrante (CRUDs):
Erick Kenzo Tanaka Okumoto: Responsável pelo CRUD de Produtos.
Eduardo Araújo Steigleder: Responsável pelo CRUD de avaliações do usuário 
João Victor Alves Benfica: Responsável pelo CRUD de campanhas das ONGs
Rafael Siqueira Furlan: Responsável pelo CRUD de solicitações.

DETALHE: A inserção de dados no CRUD "Solicitações" só será possível após a criação de ao menos 1 produto no CRUD "Produtos". Isso ocorre pois pra ter uma solicitação, deve existir ao menos um item para ser solicitado.
